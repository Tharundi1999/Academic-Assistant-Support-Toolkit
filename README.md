# Academic Assistant Support Toolkit

** MSc Advanced Computer Science – Academic Assistant Project**

## Project Overview

This repository contains seven interactive HTML-based resources developed as part of an Academic Assistant project at the University of Chester.

The resources are designed to support computing lab sessions by helping students prepare their programming environments, identify common technical problems, and understand programming errors.

## Project Artefacts

### Artefact 1 – Lab Troubleshooter

An interactive troubleshooting decision guide designed to help users identify common computing lab problems and follow suggested steps to resolve them.

**Resource:** Lab Troubleshooter

### Artefact 2 – Lab Preparation Checklists

Three interactive checklists designed to help students prepare for programming lab sessions.

**Resources:**
- Python Lab Preparation Checklist
- Java Lab Preparation Checklist
- C Lab Preparation Checklist

### Artefact 3 – Common Errors & Fixes

Three programming reference guides explaining common errors, possible causes, and suggested fixes.

**Resources:**
- Python Common Errors & Fixes
- Java Common Errors & Fixes
- C Common Errors & Fixes

## How to Use the Toolkit

1. Download this repository as a ZIP file.
2. Extract the ZIP file.
3. Open `index.html` in a web browser.
4. Select the required resource from the homepage.

The seven resources are organised into three folders. The `index.html` file provides a central homepage linking to them.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

The toolkit aims to provide accessible technical guidance for students and support academic staff during computing-related teaching and lab sessions.

These resources were developed as project artefacts.
